## 共通原則與限制

臺灣緊急救護為119。疑似心跳停止、腦中風、心肌梗塞時應立即請求救護，不因等待症狀變嚴重而延誤。地震時優先「趴下、掩護、穩住」，停搖後依現場安全與政府警報撤離。
