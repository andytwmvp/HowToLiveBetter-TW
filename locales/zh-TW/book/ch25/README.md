# 第25章：親友離世後，先安頓再按期限辦理

本章整理親友離世後的醫療、行政與財產程序。死亡登記、繼承、稅務及不動產登記各有不同期限和辦理單位，請逐項確認。

- [接運、保存及火化分開確認，先有必要證明與許可](TW-25-003.md)
- [死因有疑點先提出，證據保全與司法解剖不可混為一談](TW-25-004.md)
- [死亡登記原則30日內辦理，線上申請要確認結案](TW-25-005.md)

- [不明加價先對契約留證，申訴處理期限不是退款保證](TW-25-007.md)
- [查業者許可與真正契約對象，代辦授權不要連財產一起交出](TW-25-008.md)
- [遺屬給付、勞退、商業保險與遺產分開申請及分配](TW-25-009.md)
