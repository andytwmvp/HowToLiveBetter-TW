# 第15章：租屋與買房

本章整理租屋、買房、房貸、預售屋與房屋修繕。簽約和付款前，請核對契約內容、收款對象及適用規定；各案權利義務仍須依實際情況判斷。

- [租屋先留屋況與收款證明，押金不能當成房東任意沒收的費用](TW-15-001.md)
- [房東換鎖或停水電逼搬時先保全安全與證據，不用對抗代替法律程序](TW-15-002.md)
- [付租金前查收款授權，仲介、代管與包租的角色不能混用](TW-15-003.md)
- [包租轉租先看原租約與退場安排，不用租金貸款掩蓋業者信用風險](TW-15-004.md)
- [房子出售不一定能立即終止租約，但買賣不破租賃也有例外](TW-15-005.md)
- [租買前核對權利、授權與負擔，謄本和稅單不是相同證明](TW-15-006.md)
- [中古屋付款依權利移轉與清償條件安排，不把履約保證當成全面承保](TW-15-007.md)
- [低價隔間套房先看合法用途與逃生，不把有門牌或能申請補貼當成安全證明](TW-15-008.md)
- [買到農地不代表取得蓋住宅的資格，農舍與一般住宅分開審查](TW-15-009.md)
- [預售屋先查正式契約與履約擔保，信託兩字不等於一定完工或全額退款](TW-15-010.md)
- [貸款不足與訂金退還先看契約及責任，沒有核貸保證就不要先承諾付清](TW-15-011.md)
- [預售面積與建材變更分開核對，2%找補上限不等於3%內可以任意縮水](TW-15-012.md)
- [預售延誤分開追開工、使用執照、移轉文件與通知交屋，不把四個日期混成一個](TW-15-013.md)
- [預告登記是保全特定請求權，不是取得產權或擋住所有法拍](TW-15-014.md)
- [房貸轉貸看相同剩餘期間的總成本，月付降低不一定代表比較省](TW-15-015.md)
- [首購優惠要看申貸時適用方案，青安上限與補貼不是一定核給的貸款](TW-15-016.md)
- [管理費爭議走查帳與正式程序，管委會不能把門禁停水電當成任意催收工具](TW-15-017.md)
- [交屋驗收、契約保固與瑕疵權利分開追蹤，漏水不是只看一年保固](TW-15-018.md)
