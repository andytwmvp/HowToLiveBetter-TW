# 第7章：收入中斷時，先穩住基本生活

本章整理失業、急難救助、健保、職訓、住宅與債務等基本生活問題。補助資格及申請方式依個人條件和方案而異，請查看各篇說明。

- [非自願離職後先辦失業認定，不把離職或線上登記當成已領款](TW-07-001.md)
- [被欠薪同時保全證據與申請協處，不把勞檢裁罰當成工資已追回](TW-07-002.md)
- [負擔不起律師費仍先處理期限，法律諮詢與律師扶助分開申請](TW-07-003.md)
- [今晚無處可住時先說明所在位置與風險，由所在地社政評估安置](TW-07-004.md)
- [求職先用免費公立就服，再核對職缺及民間仲介資格](TW-07-005.md)
- [急難救助與急難紓困分清窗口，不等所有給付核定才求助](TW-07-006.md)
- [低收與中低收按家庭收入財產核算，失業不一定直接算零收入](TW-07-007.md)
- [身心障礙支持按需求分項申請，輔具先評估核定再購買](TW-07-008.md)
- [待業期間依法銜接健保，欠費協助與投保身分分開處理](TW-07-009.md)
- [重病費用先分健保、自費與生活支出，重大傷病不等於所有治療免費](TW-07-010.md)
- [身分證遺失先掛失並依法補領，另查帳戶與門號風險](TW-07-011.md)
- [特定就業支持先確認方案與受領人，不把身分類別當成補助已核准](TW-07-012.md)
- [職訓先核對學費補助與生活津貼，不能同領失業給付](TW-07-013.md)
- [求職以可調整的紀錄與回饋推進，不以大量投件當成唯一成果](TW-07-014.md)
- [求職遇押金、扣證件或交付帳戶先停下，不用借款換工作機會](TW-07-015.md)
- [租金補貼與社宅不是即時安置，先核對年度、住宅及申請完成狀態](TW-07-016.md)
- [先保住食宿、醫療與求職能力，把未核定補助排除在可用現金之外](TW-07-017.md)
- [離職後分開查健保、就保、勞保與勞退，國民年金不是任選的替代品](TW-07-018.md)
- [刑事更生保護與債務更生分清，再找適合的重建服務](TW-07-019.md)
- [商業醫療險先查保障缺口與可持續保費，不把新保單當成既有疾病的救急款](TW-07-020.md)
- [便利商店或網咖不是正式安置，無住處時安排可接續的安全方案](TW-07-021.md)
- [討薪前先查誰實際僱用與指揮，不讓承攬名稱取代勞動關係判斷](TW-07-022.md)
- [還款困難先盤點並聯繫債權人，必要時走法院債務清理而非保證銷帳代辦](TW-07-023.md)
