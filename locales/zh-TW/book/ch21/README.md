# 第21章：出國、旅行與境外安全

各國入境規定、旅遊警示、保險與檢疫要求不同，出發前請向外交部、目的地主管機關及保險公司確認最新資訊。

- [出發前分開查旅遊警示、入境條件與保險，不把沒有警示當成安全保證](TW-21-001.md)
- [把當地救援、駐外館處與外交部中心分開存，國外撥打不一定免費](TW-21-002.md)
- [領務協助能聯繫與轉介，不能改判；緊急借款例外也不是免費救助承諾](TW-21-003.md)
- [境外醫療、後送與旅遊不便險分開核對，健保核退不是海外帳單全額支付](TW-21-004.md)
- [海外高薪邀約先核對僱主、合法工作資格與退場方式，不用觀光名義掩蓋工作](TW-21-005.md)
- [出國攜帶現金申報、個人攜款上限與銀行提款規定分開查](TW-21-006.md)
- [護照遺失先聯絡警方與轄區館處，證件備份和返國文件不能取代入境資格](TW-21-007.md)
- [境外自駕先核對駕照承認、可駕車種與保險，日本不是拿臺灣國際駕照就能開](TW-21-008.md)
- [移民、留學與簽證代辦按實際業務查資格，不接受包過或假材料](TW-21-009.md)
- [邀請函只寫可證實的真實安排，不出借證件或替陌生人作不明保證](TW-21-010.md)
- [行程與聯絡約定只交給可信任的人，失聯不必等一個固定天數才求助](TW-21-011.md)
- [帶藥按成分、數量、劑型及每個入境點查規定，處方不是跨國通行證](TW-21-012.md)
- [回臺行李先逐項查動植物檢疫，主動申報不等於禁止品就能放行](TW-21-013.md)
