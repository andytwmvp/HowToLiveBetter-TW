## 稿件與全書進度

結構化草稿14章373條不變；去重涵蓋410個主題，355個尚無稿件，已有稿件但未完成審閱整合者349個。來源登錄174個ID，尚有140個來源ID、492處引用未完成登錄；同一ID可能被多處引用，登錄也不等於相關章節的主張均已查核。

[原作繁體來源稿](../../source.html)保留34章765條與搜尋、分級及長文功能。原作與未審閱草稿不能當成臺灣現行制度，來源載入失敗不回退使用它們。完整出版驗收仍應拒絕通過。

## 本地操作

```sh
node tools/offline/build.mjs
node tools/epub/build.mjs
node tools/anki/build.mjs
```

三種產物含相同61條核心正文與9則補充導航。原作預覽必須依[來源建置說明](../../REPOSITORY_GUIDE.md#source-preview)明確指定`--source-preview`。不把結構測試當成所有閱讀器或Anki用戶端匯入驗收；不發布全書定稿。
