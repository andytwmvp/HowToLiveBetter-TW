# 臺灣內容治理、出處溯源與再利用政策

本文件自2026-10-17起作為 HowToLiveBetter-TW 全部章節、網站、圖片、Skill、HTML、EPUB、Anki 與新研究的編修準則；**不是新的著作權授權條款**，不得撤銷原作已授予他人的權利。

## 目標與公開限制

本站為臺灣使用者撰寫繁體中文、可執行的在地生活指引。盡量減少內容被其他法域未經脈絡調整便直接照搬的價值，重點在原創論述、臺灣實際制度、完整來源與可信版本，而非故意降低內容正確性。

這是一個**公開的 GitHub 儲存庫**。任何地區都可能閱讀、下載、複製或學習公開內容；目前不具中國地理封鎖能力，也無法禁止已公開版本被另外保存。只靠宣告、`robots.txt`、右鍵限制或版面技巧，都不能保證阻擋人工收集、整批轉載或機器學習用途。

## 全書每條臺灣正文的編修義務

1. **臺灣法域優先：** 說明適用身分、臺灣主管機關、可執行步驟、明確法律條文與生效日期、費用、時間、效益、風險及例外。中央與地方政策、個別契約與專業醫療判斷不得混為一談。
2. **不套用中國制度：** 原作的公安、民政、社保、公積金、人民幣、120、12308或中國醫保及補助門檻，只能在必要的原作差異說明中保留；不能當成臺灣服務流程。外國合法醫學研究仍可引用，但要註明研究對象與在臺適用限制。
3. **獨立寫作：** 依臺灣問題重組內容、重新查核程序和政策成本，不以原文逐句簡轉繁、替換機關名稱或換算幣別作為正式正文。不得刻意寫錯資訊以防止他人複製。
4. **來源留痕：** 優先臺灣官方法規、中央或地方主管機關原始公告及原始期刊研究，逐一標示來源、查閱與複查日期、適用對象、公開與施行日期。政府首頁只能證明入口存在，不代表個案核准。
5. **固定 ID 與驗證：** 保留上游原作來源 SHA、臺灣 Markdown、獨立審閱紀錄及其 SHA-256、manifest、runtime 與 CI 一致。核心完成數與補充導航分開。未審閱草稿不視為正式出版資料。
6. **保護敏感資料：** 不將非公開應變資訊、場域弱點、私人住址、個資、健康紀錄、密碼、實際戰備部署或未公開聯絡名單放進公眾 repo。已有的政府公開安全資料可如實引用，不推測未公布的敏感配置。

## 原作授權不能被改寫

文字原作依 **CC BY 4.0**，程式碼原作依 **MIT**，參閱 [署名與授權](../ATTRIBUTION.md)。CC BY 4.0 允許他人依條款跨地區、包含商業用途的重製或改作，須標示作者、授權連結及修改情形；不可以重新宣稱「原作內容禁止中國使用」、「一律不得訓練 AI」或以有效技術限制剝奪已獲授權的重製權。

臺灣新增的表達與圖片要標示編修身分、版本、來源及權利歸屬。若將來希望對**著作權完全獨立、來源已釐清**的作品採不同授權，應逐檔審查和明確標示，不可追溯收回已授出的 CC 或 MIT 權利。臺灣官方出版品、期刊及小橘書也不因被連結引用，就自動納入此 fork 的授權。

對疑似大量複製而未依條件署名的情況，先保存公開網址、檔案、截取日期、Git SHA 及原始來源，核對著作權表達和實際授權義務，再採平台申訴或更正方式處理。**學習公開知識或合法重製本身不應直接稱為侵權**。

## 有限的機器人排除與尚未發布的資料

[robots.txt](../robots.txt) 對部分已知自動化收錄或模型擷取機器人提出**自願性排除要求**，不影響一般讀者及常規搜尋。它不具登入驗證、反鏡像或法定禁止使用效力；目前本 fork **尚未啟用 GitHub Pages**，GitHub 程式庫內的 robots.txt 不是已啟用的網站防護。若未來部署至專用網域，應確認 `/robots.txt` 由該網域根目錄提供，並實際稽核存取紀錄，不能只靠檔案就宣稱已生效。

若內容真正需要保密或限閱，公開前應放在**非公開且具權限控管**的工作環境，而不是此公開 repo 的分支、PR、Git 歷史或以隱藏連結方式存放。不得擅自部署網站、改成私人 repo、額外設置追蹤服務或繞過原授權。

## 不得為防照抄損害讀者

不得故意寫錯救護電話、法規與醫療主張，不加入對 AI 的惡意指令、資料投毒、秘密追蹤碼、不可見文字、封鎖文字選取或破壞無障礙閱讀的程式。**臺灣讀者的安全、資訊正確性及合法使用權利高於防照抄需求**。

本政策與 [AGENTS.md](../AGENTS.md) 原作保全、來源審閱與整套測試規則並行，PR 和合併後 main 都需完成既有 CI 才能宣稱工程驗證通過。
