# 臺灣內容治理、出處溯源與再利用政策

本文件自2026-10-17起作為 HowToLiveBetter-TW 全部章節、網站、圖片、Skill、HTML、EPUB、Anki 與新研究的編修準則；**不是新的著作權授權條款**，不得撤銷原作已授予他人的權利。

## 目標與公開限制

本站為臺灣使用者撰寫繁體中文、可執行的在地生活指引。盡量減少內容被其他法域未經脈絡調整便直接照搬的價值，重點在原創論述、臺灣實際制度、完整來源與可信版本，而非故意降低內容正確性。

這是一個**公開的 GitHub 儲存庫**。任何地區都可能閱讀、下載、複製或學習公開內容；目前不具中國地理封鎖能力，也無法禁止已公開版本被另外保存。只靠宣告、`robots.txt`、右鍵限制或版面技巧，都不能保證阻擋人工收集、整批轉載或機器學習用途。

## 全書每條臺灣正文的編修義務

1. **臺灣法域優先：** 說明適用身分、臺灣主管機關、可執行步驟、明確法律條文與生效日期、費用、時間、效益、風險及例外。中央與地方政策、個別契約與專業醫療判斷不得混為一談。
2. **不套用中國制度：** 原作的公安、民政、社保、公積金、人民幣、120、12308或中國醫保及補助門檻，只能在必要的原作差異說明中保留；不能當成臺灣服務流程。外國合法醫學研究仍可引用，但要註明研究對象與在臺適用限制。
3. **獨立寫作：** 依臺灣問題重組內容、重新查核程序和政策成本，不以原文逐句簡轉繁、替換機關名稱或換算幣別作為正式正文。不得刻意寫錯資訊以防止他人複製。
4. **來源留痕：** 優先臺灣官方法規、中央或地方主管機關原始公告及原始期刊研究，逐一標示來源、查閱與複查日期、適用對象、公開與施行日期。政府首頁只能證明入口存在，不代表個案核准。
5. **固定 ID 與驗證：** 保留上游原作來源 SHA、臺灣 Markdown、獨立審閱紀錄及其 SHA-256、manifest、runtime 與 CI 一致。核心完成數與補充導航分開。未審閱草稿不視為正式出版資料。
6. **保護敏感資料：** 不將非公開應變資訊、場域弱點、私人住址、個資、健康紀錄、密碼、實際戰備部署或未公開聯絡名單放進公眾 repo。已有的政府公開安全資料可如實引用，不推測未公布的敏感配置。

## 臺灣實際情境、發生頻率與風險分流（2026-10-18 新增）

每個新增或實質修訂的正式條目，應以**臺灣居民會遇到的實際場景**組織敘事，依據適用範圍判斷通勤、居家、職場、校園、山區、水域、醫療照護、颱風地震等情境是否相關；不得為了「在地化」機械式插入不相干的地名或案例。

- **發生頻率的最低證據契約：** 優先尋找臺灣主管機關、官方統計資料庫、監測年報或有明確母群的臺灣原始研究；寫明統計年份或期間、全國或縣市、病例／事件定義、分子、分母、單位（例如每十萬人口、每年件數或急診就診人次）、資料來源及查閱日期。跨年度趨勢須考慮通報制度或分類變更；不得把件數、盛行率、發生率、致死率、急診就診率混為一談。
- **判斷軸分開記錄：** 臺灣法律禁止或規範、權利義務、情境在地代表性、發生頻率與分母、傷害嚴重度及可採取行動須分別核對。法律禁止的行為不能只用高低頻率描述，也不能因頻率資料不足而弱化法定界線；須交代具體法源、行為邊界及適用日期。
- **避免不實精確：** 找不到可核實的臺灣發生頻率時，明寫「目前未取得可比較的臺灣統計數據」，而不是套用其他國家比率或臆測「每年多少人」；若只有國際研究，將其標為國際背景且解釋適用限制。官方僅公布全國數字時，不得推算成個別縣市、年齡層或個人風險。
- **風險分層與實際用途：** 說明是否有臺灣常見暴露情境、季節性、年齡及職業差異；僅在原始資料確有分層時寫明。對「少見但可能致命」的情況仍須清楚列出立即求援的警訊，不能因低頻率降低優先級。對資料來源中沒有的因果關係，不可由相關性自行推斷。
- **原作情境的在地適配：** 回溯時辨識是否依賴特定國家的地形、氣候、動植物、交通或服務情境。若對臺灣讀者缺乏代表性，改用傷害機制相關、且有臺灣來源支持的在地行動指引；但低頻而可能造成重大傷害的風險仍保留精簡警示。不得把類似情境說成頻率或危害完全相同，兩者統計與限制分開交代。
- **跨領域適配，不限自然環境或安全案例：** 上述檢查不限於例示主題，也適用於醫療與照護流程、金融與支付、詐騙手法、住房租賃、工作與校園、消費、社福、行政及司法求助等任何生活情境；列舉不是完整清單。逐條確認臺灣居民實際接觸的制度、服務入口、交易方式、法律界線、家庭與工作情境；只替換地名、機關或貨幣不足以完成在地化。若原情境在臺灣不具代表性，應以同一問題機制下有臺灣證據支持、讀者可以實行的情境取代；若沒有可比的在地情境或統計，明示缺口並保留必要安全行動。行為是否合法或受規範必須獨立記錄，不得只用高低頻率描述或以缺乏頻率資料淡化臺灣的法律界線。
- **行動優先於統計：** 急救、災害與重大公共安全條目先寫現場立即可做及不能做的安全步驟、119等正確求援入口和專業接手界線，再提供發生頻率作背景；查詢數字、成本評估或比對警訊不得延誤救援。
- **跨制度適用與時效：** 臺灣中央與地方的實際服務、申請門檻、有效日期及可近性不同時須區分；物價、交通與就醫成本標記估計地區和月份，不把單一城市的情況當成全臺普遍值。
- **審閱可追溯：** 將頻率來源與正文主張連結至既有來源登錄與逐條審閱紀錄；資料不完整或已過期時保留待審，不得只因補上描述就把未核對條目改成 verified。新增資料不得影響原作授權、固定 ID、正文 SHA-256、共用 runtime 或既有的驗證門檻。

臺灣新增的表達與圖片要標示編修身分、版本、來源及權利歸屬。若將來希望對**著作權完全獨立、來源已釐清**的作品採不同授權，應逐檔審查和明確標示，不可追溯收回已授出的 CC 或 MIT 權利。臺灣官方出版品、期刊及小橘書也不因被連結引用，就自動納入此 fork 的授權。

對疑似大量複製而未依條件署名的情況，先保存公開網址、檔案、截取日期、Git SHA 及原始來源，核對著作權表達和實際授權義務，再採平臺申訴或更正方式處理。**學習公開知識或合法重製本身不應直接稱為侵權**。

## 不得為防照抄損害讀者

不得故意寫錯救護電話、法規與醫療主張，不加入對 AI 的惡意指令、資料投毒、隱藏追蹤碼、不可見文字、封鎖文字選取或破壞無障礙閱讀的程式。**臺灣讀者的安全、資訊正確性及合法使用權利高於防照抄需求**。
