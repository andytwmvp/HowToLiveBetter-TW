# 繁體中文與臺灣用語規範

顯示語系使用 zh-TW；正文與中文路徑先以 OpenCC 1.1.9 的 s2tw.json 轉換字形。來源網址及授權不翻動；不對政府機關、法規名稱或研究結果機械套用臺灣制度。引用轉字後不是逐字原文，引文原貌從固定 Git 版本與官方來源核對。

介面統一用語：帳號、登入、設定、預設、驗證碼、簡訊、軟體、硬體、伺服器、網路、資訊、資料、文件、連結、使用者、建立、刪除、備份、權限、載入、快取、影片、滑鼠、身分證、睡眠品質。法規名稱、機關名稱及程式識別碼依語境保留，不一律換詞。

不得把社保直接換成勞保、把人民幣金額改標新臺幣、把中國電話直接當成臺灣窗口，也不得以繁體字形完成宣稱臺灣法規或醫療查核完成。

圖片依序處理文字模板、SVG、PNG／JPG／WEBP；文字模板須以臺灣繁體字型重新輸出，且檢查字型載入、尺寸與文字溢出。無文字 SVG 圖示可以保留；原作者廣告不得復原。外部服務動態徽章須檢查其 URI 編碼中的文字，不只檢查 alt。

原始中文路徑以百分比編碼儲存在對照清單，避免把識別路徑當成可任意翻譯的文案。資料版本、字形完成狀態、來源查核狀態與臺灣適用性分開記錄。舊版 bootstrap.py 的 --apply 已停用。

在 /mnt/data 或 /tmp 建立的暫存／中間檔案，不再需要時必須清除。不得刪除使用者原始檔案，也不得把字型、token 或私人對話提交至儲存庫。
