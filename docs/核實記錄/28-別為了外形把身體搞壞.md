# 第 28 節「別為了外形把身體搞壞」· 核實記錄（2026-09-08）

## 關於「MTF」那半句的處理（寫作決定，非事實核對）

用戶原話裡有「跟風網上 MTF，不被定義性別」。本節**沒有**按「別跟風變性」來寫，改寫成第 7 條「性激素類藥只在醫生開方並定期複查的前提下用，不要網購、不要自己加量」，理由三條：

1. 證據對得上的是用藥方式，不是用藥動機。Getahun 2018 測的是跨性別女性與順性別對照的血管事件差異，它支持的結論是「用雌激素的人需要長期血管監測」，不支持「不該用」。把它寫成勸退，是拿這份數據說了它沒說的話，違反本項目「數字必須能在原文中找到」的規則。
2. 規範醫療路徑在國內是存在的（內分泌科或相應專科評估、開方、隨訪），把它和黑市渠道一起勸退，實際效果是把人推向後者——那正是風險最高的一條路。
3. 同一條規則天然覆蓋用戶列舉的其餘兩項：避孕藥／更年期激素／睪酮補充的自行加量，以及第 5 條的合成代謝類固醇。寫成「憑處方 + 定期複查」一條線，比按人群分類更準也更短。

本節引言裡寫明「不評價任何人想把自己變成什麼樣子」，把範圍限定在「有處方、有資質、有複查」與「網購、非正規機構、自行加量」兩條路的風險差。用戶提的「覺得自己丑」另落為第 8 條（軀體變形障礙先評估），是這部分訴求裡唯一有量化文獻支撐的落點。
