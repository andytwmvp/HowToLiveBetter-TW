# 第 1 節來源核實記錄

核實日期 2026-09-07。多數出版社站點（NEJM、Elsevier、Wiley、BMJ、AHA）對 WebFetch 返回 403，這些文獻通過 Europe PMC REST 接口（`<https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:">…"&resultType=core&format=json`）讀取了同一 DOI 對應記錄的標題、作者、期刊、年份和摘要全文；doi.org 本身能解析（302 到出版社）。以下「原文」均為從摘要/正文中抓到的原句。
