# 追加：第 8 節第 3 條併入屏幕共享詐騙

2026-10-14。候選是「陌生人以客服、警察、平臺退款、貸款審核等名義讓你打開屏幕共享，一律拒絕掛斷」。

## 為什麼併入、不另開
- 第 8 節第 3 條（反詐硬規則）的成本欄和說人話裡原本就寫著「凡是讓你轉賬、共享屏幕、下載陌生 App、點鏈接、報驗證碼的，先掛斷」。動作相同，按「不寫重複條目」第三問並進這一條。
- 原條缺的是「為什麼共享屏幕危險」，所以只在收益欄「冒充客服」一類後面補了機制和警方提示兩句，來源欄補兩個鏈接。
- 說人話原來就有「共享屏幕」，且已經 114 字，接近 120 字上限，沒動。
- 證據等級、收益量級不變（B、大）：新增的仍是官方宣傳口徑，沒有「照做之後少被騙多少」的數字。
- 工信部、國家反詐中心 App 的原文沒取到（mps.gov.cn 長期不可達），改用福建省公安廳識騙技巧專欄，和本條既有來源同一個欄目。

## 1. 福建省公安廳·識騙技巧：警惕「共享屏幕」類詐騙手段（2022-08-18，來源福建警方防騙諮詢熱線）
- URL：<https://gat.fujian.gov.cn/ztzl/fjjffpzxrx/spjq/202208/t20220818_5977906.htm>（2026-10-14 curl 直取）
- 「一旦下載會議APP，輸入"會議ID"……讓你點擊"共享屏幕"，點擊開始，就會開始所謂的"視頻會議"，緊接著你在手機上所有的操作，包括消息彈窗、短信驗證碼、密碼輸入等都會被看得一清二楚。」
- 「陌生人要求你下載APP，讓你開通"共享屏幕"的一定是盯上你的錢」
- 頁面案例：冒充京東金融客服稱取消校園貸，視頻會議並共享屏幕，被騙 136037 元（只作「發生過」用，沒寫進條目）。

## 2. 福建省公安廳·識騙技巧：「中銀會議」「銀聯會議」「抖音會議」這些APP都是詐騙軟件（2025-05-12，轉載上海反詐中心）
- URL：<https://gat.fujian.gov.cn/ztzl/fjjffpzxrx/spjq/202505/t20250512_6912823.htm>（2026-10-14 curl 直取）
- 「通過'屏幕共享'功能，騙子能夠看到事主在手機上的所有操作，事主輸入的銀行卡賬號、密碼、驗證碼一覽無餘，通過'遠程控制'甚至能夠直接操控事主的手機，最終完成轉賬詐騙。」
- 警方提示：「凡是提到"會議號""屏幕共享""遠程控制"的都是詐騙。」
