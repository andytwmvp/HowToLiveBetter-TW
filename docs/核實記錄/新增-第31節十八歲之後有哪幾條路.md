## 兩處必須記住的更正

- **《退役士兵安置條例》（國務院、中央軍委令第 608 號，2011 年）已於 2024 年 9 月 1 日廢止**，現行是《退役軍人安置條例》（第 787 號），第九十三條寫明「本條例自2024年9月1日起施行。《退役士兵安置條例》同時廢止」。安排工作的條件表述變了：舊版是「士官服現役滿12年」「平時榮獲二等功以上獎勵或者戰時榮獲三等功以上獎勵」，新版是「軍士服現役滿12年」「個人獲得勳章、榮譽稱號」「個人榮獲三等戰功、二等功以上獎勵」「個人獲得一級表彰」，另加因戰致殘 5 至 8 級和烈士子女。網上攻略普遍還在引舊條例。
- **服兵役學費補償的現行標準是本專科 20000 元、研究生 25000 元**（2024 年秋季學期起）。沿革：8000/12000（財科教〔2019〕19 號）→ 16000/20000（教財〔2023〕4 號）→ 20000/25000（財教〔2024〕188 號）。檢索中從未出現過 12000/16000 這一對，遇到就是抄錯的。退役軍人事務部 2022 年的政策摘要裡仍寫 8000/12000。

另有一處要點：**《公務員錄用規定》裡沒有「定向考錄」條款**。全文逐字通讀後檢索，「基層」「定向」「服務基層項目」「退役」四個詞出現 0 次；《公務員法》也只有一句「上級機關應當注重從基層機關公開遴選公務員」。定向考錄的真實依據是中辦國辦 2017 年那份《關於進一步引導和鼓勵高校畢業生到基層工作的意見》和人社部發〔2021〕32 號裡的 10% 硬指標，第 7 條據此掛來源。

## 本輪新增的工具與站點實測結果

- **`flk.npc.gov.cn`（國家法律法規數據庫）的後端 API 是本輪最大的收穫**，全國人大制定的法律終於能逐字取全文：`POST /law-search/search/list`（Content-Type application/json，body 的鍵必須給全，少一個返回 code 500），返回 `rows[].bbbs/sxx`，**`sxx` 就是效力狀態：3 有效、2 已修改、1 已廢止、4 尚未生效**——608 號安置條例已廢止就是這麼發現的；再 `GET /law-search/download/mobile?format=docx&bbbs=<id>&fileId=` 下 docx，解 zip 取 `word/document.xml` 去標籤即得逐字全文。引用時用 `https://flk.npc.gov.cn/detail?id=<bbbs>`（頁面本身只有 552 字節的 SPA 殼，瀏覽器能看、腳本抓不到正文）。注意該 API 返回 JSON 裡的 title 是 UTF-8 被當 GBK 讀的亂碼，跟 gov.cn 的 latin-1 亂碼不是同一種，別用同一個還原函數。
- **`.doc` 附件用 `/mingw64/bin/antiword -m UTF-8.txt` 能逐字取中文**，比 pdftotext 那條路好用；gov.cn 通知頁的附件裡 .doc 很多（成人高招辦法、西部計劃協議書都是這麼取的）。附件 URL 要從通知頁正則出 `href="./P0…"` 再拼同目錄絕對地址。
- 可用且能逐字取正文：`www.gov.cn`（政策庫 JSON + zhengceku + gongbao）、`www.mod.gov.cn`（國防部）、`www.12371.cn`（共產黨員網，黨內法規）、`www.moe.gov.cn` 正文頁與欄目索引頁（站內搜索 so.moe.gov.cn 是 JS 渲染，抓不到）、`www.mva.gov.cn` 正文頁、`jyt.hunan.gov.cn` 等省級教育廳、`xibu.youth.cn`（正文頁可開，但列表頁給的鏈接 id 與文章對不上，要按標題二次核對）。
- 不可用：`www.chsi.com.cn` 恆 412；`www.mva.gov.cn/gongkai/zfxxgkpt/...` 子欄目 403；`mohrss.gov.cn` 本輪未嘗試，人社部的 4 份文件全部從 gov.cn 轉載取到。
- **搜索引擎給的 gov.cn 老新聞 URL 大量 404**，本節所有 30 個外鏈在寫完後統一跑了一次可達性檢查，全部返回 200。
