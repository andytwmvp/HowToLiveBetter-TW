# 第 2 節第 26 條補充：茶葉黴菌毒素與綠茶提取物（2026-09-23）

任務來源：GitHub issue #27（ccpfucker），標題「反對喝茶有益健康的觀點」。原文主張「沒事喝點水和進口純牛奶，少去喝茶」，理由是茶葉可能被黴菌毒素汙染、高濃度茶提取物有肝毒性，結論是「喝茶有益健康」不能作為普遍結論，茶應當看成普通飲料。附了三篇文獻。

## 處理決定

**不改結論、不改證據等級、不改標題。** 三篇文獻自己的結論都是「按正常喝茶的量沒有風險」：第一篇暴露量低於 JECFA 可接受值，第二篇明寫中國人群通過喝茶沒有膳食風險，第三篇明寫沖泡茶不出現肝臟不良事件。它們駁不倒 China-PAR 的死亡率關聯，issue 的結論比它引的證據走得更遠。「進口純牛奶」替代的建議 issue 沒給證據，不採納。

**採納的部分寫進備註。** 讀者確實可能擔心發黴茶葉，也確實有人拿綠茶提取物膠囊當「喝茶」的替代，這兩件事條目原來沒說。所以備註補兩段：黴菌毒素的檢出情況和風險評估結論、提取物與沖泡茶的區別，落點是「這條只算泡的茶，別拿提取物保健品代替」。三篇文獻按規矩全部進來源欄，備註不帶鏈接。

**「受潮發黴的別喝」是常識性提示（C 級口徑），沒有單獨來源。** issue 提到儲存條件影響安全性，但三篇文獻都沒給儲存方面的數字，所以只寫動作不寫數字。

**「爭議」開頭保留，量級不動。** 收益欄沒改，說人話也不用改。
