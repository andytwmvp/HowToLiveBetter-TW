# issue #37：職稱怎麼報、怎麼考、別踩什麼坑（2026-09-27）

任務來源：GitHub issue #37（superman-death），問能不能完善職稱方面的信息：怎麼獲取、準備什麼資料、去什麼機構。

## 範圍怎麼定的

此前全書沒有專業技術職稱的條目，只在第 24、31、32、33 節順帶提到。第 23 節第 8、11 條講的是職業資格和技能等級，不是職稱。

不開新節，在第 23 節末尾追加 4 條（第 20 到 23 條），不插中間，避免第 14 到 19 條被順延（這幾條被別處引用了十幾次）。

「準備什麼資料」沒有寫成清單。職稱分 27 個系列，材料清單、申報時間和業績條件由各系列、各省每年的申報通知定，全國沒有統一版本。逐項寫就成了沒法維護的地方辦事指南。正文只指路：先找本省人社廳當年的申報通知。

## 沒寫的

- 「職業資格與職稱對應關係」的具體對照表：政策文件庫按標題查不到，只引了 2016 年意見裡的原則性規定。
- 積分落戶、人才補貼看職稱：各地政策不同，沒有找到全國性原文，第 23 條備註裡沒寫。
- 各系列是否統考：只核了會計一個系列，其他系列讓讀者查該系列的「深化××職稱制度改革的指導意見」。

## 收益量級怎麼定的

- 第 20、21 條：口徑定為時間，效果是一次性少跑彎路，按閾值套「小」。
- 第 22 條：口徑定為自由，後果是撤銷職稱、3 年失信記錄、3 年內不能申報，性質接近行政處理，按「避免行政處罰」套「中」。
- 第 23 條：口徑定為金錢，但文件裡沒有「評上漲多少」的數字，憑判斷定「小」，證據等級 B。
