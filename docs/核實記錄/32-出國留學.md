# 第 32 節 出國留學：身份、打工、保險和回國認證 · 核實記錄（2026-09-18）

任務來源：倉庫 issue #8 讀者問「有沒有給常見留學國家留學生的建議，比如美國、加拿大、英國、澳大利亞，身為留學生有什麼權益、如何維護」。

原有覆蓋：第 21 節寫的是出國與境外安全（外交部安全提醒、12308、領事保護邊界、境外醫療與轉運保險、境外高薪招聘陷阱），不含留學生身份與學業。第 23 節寫學歷回報，不含境外學歷認證。所以新開一節，不與兩節重複，正文裡做了互相指路。

落點：新增 `book/32-出國留學.md`，10 條。覆蓋國家按讀者提問限定為美國、加拿大、英國、澳大利亞，逐國寫數字。**本節所有外國政策數字標註截至 2026 年 9 月，正文和節首都寫明要讀者按來源鏈接自查，不長期維護。**

取源工具：本機 curl 段錯誤、`Invoke-WebRequest` 對 canada.ca 與 cscse.edu.cn 超時或斷連，改用無頭 Chrome `--dump-dom` 取渲染後 DOM（jsj.moe.gov.cn 與 immi.homeaffairs.gov.au 是前端渲染，必須走這條路）。全節 17 條外鏈在 2026-09-18 逐條跑過可達性，除 canada.ca 外均返回 200；canada.ca 本機 PowerShell 取不到但無頭 Chrome 可取全文，內容已逐字核對。

- 各國的稅務申報義務（如美國 F-1 無收入也需報送表格）本輪未取得可逐字核對的官方頁面，未寫入。
