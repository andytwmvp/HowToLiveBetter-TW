# 追加：讀書還是初中畢業去打工 · 核實記錄（2026-09-10）

任務來源：讀者問「到底是接著讀書好，還是讀完初中就去打工好」，並舉了兩個常見說法——「有些沒文化的當老闆」「有些 985 送外賣」。

原有覆蓋：全書只有第 23 節原第 1 條（全球教育回報率 9%）沾邊，而且它明說「不是中國的具體數字，只能當量級參照」。搜「童工」「義務教育」「助學金」「助學貸款」「中職」「職業教育法」在 book/ 下全部零命中；「倖存者偏差」只在第 23 節原第 6 條備註裡出現一次，說的是招聘平臺工資數，不覆蓋學歷。也就是說「要不要接著讀」這一層是完全空白的，原第 23 節默認讀者已經決定「學點東西」，只回答「學什麼」。

落點：第 23 節前面新增 6 條，原第 1 至 7 條順延為第 7 至 13 條，節首導語改寫成「前六條回答還要不要接著讀、後七條回答怎麼挑」。放第 23 節而不是新開一節，是因為這六條和後七條共用同一把尺子（花掉多少錢和時間、換回多少收入），拆開會讓兩邊都要重複解釋教育回報率。全書 473 → 479 條，A 級 301 → 306，B 級 123 → 124，C 級 49 條不變，文獻鏈接 918 → 927，爭議標註 43 → 44，TODO 36 處不變。
