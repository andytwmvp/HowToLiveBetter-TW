# 第 6 節來源核實記錄

核實方式說明：doi.org 全部返回 302 跳轉；JAMA/NEJM/Elsevier/Wiley/ACP/RSNA/Nature 的出版社頁面對 WebFetch 返回 403，PubMed 頁面只返回 cookie 提示。因此摘要正文統一通過 Europe PMC 官方 REST 接口（`<https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:<doi>&resultType=core&format=json`>，返回 PubMed 同源的題錄與 abstractText）核實；個別用 NCBI E-utilities efetch。以下「實際打開的 URL」即為核實時 WebFetch 成功返回內容的地址。所有 DOI 均在 Europe PMC 返回的題錄中與標題/作者/年份一一對應。
