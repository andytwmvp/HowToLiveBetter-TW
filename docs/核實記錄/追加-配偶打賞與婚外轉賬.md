# 追加：第 10 節第 22 條，配偶拿共同的錢打賞主播、轉給婚外的人

2026-10-14。追加在節末，沒有插在中間。節首導覽「錢和債」一塊掛上了這一條。

## 和任務原稿不一樣的地方

- 原稿把打賞和婚外轉賬合成一句「可以起訴要回轉出去的錢」。解釋（二）對兩種情形給的出路不一樣：第七條（婚外贈與）明寫贈與無效、按民法典第一百五十七條返還；第六條（直播打賞）只給婚內分割和離婚時少分、不分，沒寫能向主播或平臺要回。所以標題寫成「轉給婚外的人的錢可以起訴要回」，打賞只寫分財產，備註裡點明打賞沒寫能要回。
- 婚內分割之後財產歸屬、訴訟時效，都沒有逐字核到原文，沒寫。

## 證據等級與收益量級

- 證據等級 A：法律和司法解釋原文，加最高法同日發佈的典型案例。
- 收益量級「大」：金錢口徑按金額套，典型案例四判返還 56 萬元，是萬元級。
- 成本標籤：錢=多（律師費上千元起）；時間=中（整理證據是一次性的小時級）；毅力=些。

## 1. 民法典
- URL：<https://www.spp.gov.cn/spp/fl/202006/t20200602_463888.shtml>（最高人民檢察院轉載）
- 第一千零六十二條第二款：「夫妻對共同財產，有平等的處理權。」
- 第一千零六十六條：「婚姻關係存續期間，有下列情形之一的，夫妻一方可以向人民法院請求分割共同財產：（一）一方有隱藏、轉移、變賣、毀損、揮霍夫妻共同財產或者偽造夫妻共同債務等嚴重損害夫妻共同財產利益的行為；（二）一方負有法定扶養義務的人患重大疾病需要醫治，另一方不同意支付相關醫療費用。」
- 第一千零九十二條：「夫妻一方隱藏、轉移、變賣、毀損、揮霍夫妻共同財產，或者偽造夫妻共同債務企圖侵佔另一方財產的，在離婚分割夫妻共同財產時，對該方可以少分或者不分。離婚後，另一方發現有上述行為的，可以向人民法院提起訴訟，請求再次分割夫妻共同財產。」
- 第一百五十七條：「民事法律行為無效、被撤銷或者確定不發生效力後，行為人因該行為取得的財產，應當予以返還；不能返還或者沒有必要返還的，應當折價補償。……」
- 第一千零四十三條：「夫妻應當互相忠實，互相尊重，互相關愛」。

## 2. 解釋（二）（法釋〔2025〕1 號）
- URL：<https://www.court.gov.cn/zixun/xiangqing/452771.html>（最高法 2025-01-15 發佈頁，附全文）
- 施行：「已於2024年11月25日經最高人民法院審判委員會第1933次會議通過，現予公佈，自2025年2月1日起施行。」
- 第六條：「夫妻一方未經另一方同意，在網絡直播平臺用夫妻共同財產打賞，數額明顯超出其家庭一般消費水平，嚴重損害夫妻共同財產利益的，可以認定為民法典第一千零六十六條和第一千零九十二條規定的“揮霍”。另一方請求在婚姻關係存續期間分割夫妻共同財產，或者在離婚分割夫妻共同財產時請求對打賞一方少分或者不分的，人民法院應予支持。」
- 第七條第一款：「夫妻一方為重婚、與他人同居以及其他違反夫妻忠實義務等目的，將夫妻共同財產贈與他人或者以明顯不合理的價格處分夫妻共同財產，另一方主張該民事法律行為違背公序良俗無效的，人民法院應予支持並依照民法典第一百五十七條規定處理。」
- 第七條第二款：「夫妻一方存在前款規定情形，另一方以該方存在轉移、變賣夫妻共同財產行為，嚴重損害夫妻共同財產利益為由，依據民法典第一千零六十六條規定請求在婚姻關係存續期間分割夫妻共同財產，或者依據民法典第一千零九十二條規定請求在離婚分割夫妻共同財產時對該方少分或者不分的，人民法院應予支持。」

## 3. 涉婚姻家庭糾紛典型案例（案例四）
- URL：<https://www.court.gov.cn/zixun/xiangqing/452761.html>（2025-01-15，與解釋（二）同日發佈，共四個案例，只有案例四相關；沒有打賞案例）
- 基本案情：「婚姻關係存續期間，高某某與葉某某存在不正當關係，並於2019年3月至2023年9月向葉某某共轉賬73萬元。同期，葉某某向高某某迴轉17萬元，實際收取56萬元。」
- 裁判結果：「高某某未經另一方同意，將夫妻共同財產多次轉給與其保持不正當關係的葉某某，違背社會公序良俗，故該行為無效，葉某某應當返還實際收取的款項。對葉某某關於部分款項已消費的主張，不予支持。」
- 典型意義：「權益受到侵害的夫妻另一方主張該民事法律行為無效並請求返還全部財產的，人民法院應予支持。不能因已消費而免除其返還責任。」
- 條目裡按性別中立寫成「一方」，沒寫案中當事人性別。
