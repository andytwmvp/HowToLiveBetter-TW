# issue #44：第 16 節第 9 條補降尿酸藥的選擇與鹼化尿液

2026-09-29。讀者指出第 16 節第 9 條（確診痛風就長期吃降尿酸藥）只寫了別嘌醇，並提出四點：

1. 抑制尿酸生成的藥裡，主力是非布司他，比別嘌醇用得更廣。
2. 促進尿酸排洩的藥，主力是苯溴馬隆，另有丙磺舒、多替諾雷，多替諾雷可能是將來的主力。
3. 吃苯溴馬隆排尿酸，推薦用碳酸氫鈉鹼化尿液。
4. 依據：中華醫學會《中國高尿酸血癥與痛風診療指南（2019）》和《痛風及無症狀高尿酸血癥基層診療指南（2024 年）》。

## 處理結論

條目的主線不變：確診痛風要長期吃降尿酸藥、按血尿酸調劑量達標。讀者提的是「選哪種藥」，這一層確實有分歧，原條目只寫了美國指南的首選，沒交代。所以在收益欄末尾補了正反兩方的證據，備註開頭加了「爭議」。

- 第 1 點：「用得更廣」是用藥現狀，不是證據。更該寫的是非布司他的心血管安全性之爭，已補 CARES 和 FAST 兩項隨機試驗。
- 第 2 點：補了一句「國內還能買到苯溴馬隆」。丙磺舒、多替諾雷沒寫。多替諾雷在國內獲批的信息只找到企業新聞稿，沒有找到藥監局原文；「將來的主力」是預測，不進正文。
- 第 3 點：這裡正好有分歧，已寫進備註。美國指南有條件地不建議鹼化尿液，證據確定性很低，但要求多喝水。國內指南的具體推薦原文沒能取到，見下。
- 第 4 點：國內指南的全文都在付費庫裡，只取到了摘要。讀者引的第二份是基層診療指南（2024 年），連摘要都沒找到；正文提到的「2024 更新版」是中華醫學會內分泌學分會的另一份《中國高尿酸血癥與痛風診療指南(2024)》，兩者不是同一份文件。
