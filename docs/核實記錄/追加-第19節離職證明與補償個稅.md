# 追加：第 19 節第 17、18 條，離職證明與離職補償的個稅

2026-10-01。兩條都追加在節末，沒有插在中間，免得後面的條號整體順延。寫之前 grep 過全書，「離職證明」「一次性補償收入」「164 號」都沒有現成條目。順手在第 4 條（被裁先算清 N）備註裡指向第 18 條，在第 8 條（離職前存證據）備註裡指向第 17 條。節首引言把「最後七條講職業病和工傷」改成「接著七條」，並補了一句節末三條講什麼（原來的說法在第 16 條加進來之後就已經不準了）。第 7 節第 1 條（失業保險金）這一輪沒有改，那邊還沒有指回第 17 條。

## 1. 勞動合同法（第五十、八十九、九十一條）
- URL：<https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf74d7106b3>（國家法律法規數據庫，經 API 下載 docx 逐字核對）
- 效力：flk 返回 sxx=3（有效），公佈 2012-12-28，施行 2013-07-01，是現行的 2012 修正本。
- 原文：第五十條「用人單位應當在解除或者終止勞動合同時出具解除或者終止勞動合同的證明，並在十五日內為勞動者辦理檔案和社會保險關係轉移手續。」「勞動者應當按照雙方約定，辦理工作交接。用人單位依照本法有關規定應當向勞動者支付經濟補償的，在辦結工作交接時支付。」
- 原文：第八十九條「用人單位違反本法規定未向勞動者出具解除或者終止勞動合同的書面證明，由勞動行政部門責令改正；給勞動者造成損害的，應當承擔賠償責任。」
- 原文：第九十一條「用人單位招用與其他用人單位尚未解除或者終止勞動合同的勞動者，給其他用人單位造成損失的，應當承擔連帶賠償責任。」
- 寫法上的取捨：「新單位要看離職證明」沒有找到直接規定，所以條目只寫第九十一條的連帶責任，並說離職證明是「已經解除合同的書面憑據」，不寫「新單位一定會要」。

## 2. 勞動合同法實施條例（第二十四條）
- URL：<https://flk.npc.gov.cn/detail?id=ff8080816f3cbb3c016f40927caf049c>
- 效力：sxx=3（有效），國務院令第 535 號，2008-09-18 公佈施行。
- 原文：「用人單位出具的解除、終止勞動合同的證明，應當寫明勞動合同期限、解除或者終止勞動合同的日期、工作崗位、在本單位的工作年限。」
- 四樣裡沒有離職原因，備註裡「條例要求寫的四樣裡沒有離職原因」即據此。

## 3. 失業保險條例（第十六條）
- URL：<https://xzfg.moj.gov.cn/front/law/detail?LawID=517>（司法部行政法規庫）；flk 檢索 sxx=3（有效），1999-01-22。
- 原文：「城鎮企業事業單位應當及時為失業人員出具終止或者解除勞動關係的證明，告知其按照規定享受失業保險待遇的權利，並將失業人員的名單自終止或者解除勞動關係之日起7日內報社會保險經辦機構備案。」「城鎮企業事業單位職工失業後，應當持本單位為其出具的終止或者解除勞動關係的證明，及時到指定的社會保險經辦機構辦理失業登記。失業保險金自辦理失業登記之日起計算。」
- 未核到：現在網上申領失業保險金時是否仍要上傳這份證明。12333 辦事指南頁用無頭 Chrome 取回為空。條目只寫條例原文，不寫「網上申領要不要傳證明」。

## 4. 過程成本
- 勞動爭議調解仲裁法（<https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf64f28039d>，sxx=3）：第二條把「因訂立、履行、變更、解除和終止勞動合同發生的爭議」「因除名、辭退和辭職、離職發生的爭議」列入適用範圍；第二十七條「勞動爭議申請仲裁的時效期間為一年」；第四十三條受理後「四十五日內結束」「延長期限不得超過十五日」；第五十三條「勞動爭議仲裁不收費」。
- 勞動保障監察條例第十七條（<https://www.gov.cn/gongbao/content/2004/content_63042.htm>）：「應當自立案之日起60個工作日內完成；對情況複雜的……可以延長30個工作日」。
- 訴訟費用交納辦法（國務院令第 481 號）：第六條列的訴訟費用只有案件受理費、申請費和證人等出庭費用，不含律師費；第十三條第（四）項「勞動爭議案件每件交納10元」；第二十九條「訴訟費用由敗訴方負擔」。
- 「損失要你自己拿證據證明」是按第八十九條「給勞動者造成損害的」推出來的寫法，沒有引具體判例。

## 5. 財稅〔2018〕164 號（第五條第（一）項、第八條、第九條）
- URL：<https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202364/content.html>（國家稅務總局政策法規庫）；成文日期 2018-12-27。
- 原文：第五條第（一）項「個人與用人單位解除勞動關係取得一次性補償收入（包括用人單位發放的經濟補償金、生活補助費和其他補助費），在當地上年職工平均工資3倍數額以內的部分，免徵個人所得稅；超過3倍數額的部分，不併入當年綜合所得，單獨適用綜合所得稅率表，計算納稅。」
- 原文：第八條「除上述銜接事項外，其他個人所得稅優惠政策繼續按照原文件規定執行。」第九條「本通知自2019年1月1日起執行。」第九條同時廢止了財稅〔2001〕157 號第一條、國稅發〔1999〕178 號、國稅發〔2000〕77 號。
- 執行期限：第一條（全年一次性獎金）、第二條（上市公司股權激勵）原文帶「在2021年12月31日前」；第五條第（一）項沒有任何期限字樣。
- 效力狀態：法規庫頁面沒有顯示效力標註（「註釋」彈窗在靜態頁和無頭 Chrome 渲染後都是空的）。按全文判斷：第五條第（一）項無截止日期；後續的財政部 稅務總局公告 2023 年第 30 號（<https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211524/content.html>）只延續全年一次性獎金，原文「本公告執行至2027年12月31日」，沒有提到解除勞動關係補償。在法規庫按「解除勞動關係取得一次性補償收入」「經濟補償金 個人所得稅」檢索，沒有檢到廢止或修改這一項的文件。
- 財稅〔2001〕157 號（<https://fgk.chinatax.gov.cn/zcfgk/c102416/c5202764/content.html>）第二條仍有效：補償收入裡按規定實際繳納的住房公積金、醫療保險費、基本養老保險費、失業保險費，可以在計稅時扣除。這一項用到的人少，沒寫進條目。

## 6. 個人所得稅法（第三、九條，稅率表一）
- URL：<https://flk.npc.gov.cn/detail?id=2c909fdd678bf17901678bf724bd0609>；sxx=3（有效），2018-08-31 公佈，2019-01-01 施行。
- 原文：第三條「綜合所得，適用百分之三至百分之四十五的超額累進稅率」；稅率表一「不超過36000元的」3%，「超過36000元至144000元的部分」10%，「超過144000元至300000元的部分」20%，「超過300000元至420000元的部分」25%。第九條「以支付所得的單位或者個人為扣繳義務人」。
- 例子的算法：超出 3 倍的 6 萬元，36000×3% + 24000×10% = 1080 + 2400 = 3480 元。整筆 36 萬元按同一張表：36000×3% + 108000×10% + 156000×20% + 60000×25% = 1080 + 10800 + 31200 + 15000 = 58080 元。

## 沒有寫進去的
- 代通知金（第 5 條）和違法解除賠償金（第 6 條，2N）算不算「一次性補償收入」：164 號只點名了經濟補償金、生活補助費和其他補助費。在法規庫檢索「違法解除勞動合同 賠償金」「代通知金」，沒有檢到總局的文件或答覆。條目備註只寫「文件沒有單獨點名，拿不準打 12366 問當地稅務局」，不下結論。
- 「當地上年職工平均工資」具體用哪個口徑（城鎮非私營單位還是全口徑、省還是市）：文件沒有定義，條目寫「以當地稅務局為準」。
- 「個人所得稅 App 能查到每筆收入的申報明細」是作者經驗，只放在成本欄，沒有寫成收益。

## 收益量級與證據等級
- 第 17 條：證據 A（法律、行政法規原文）。收益定「中」、口徑「金錢」。證明本身不直接換來錢，它保住的是按時辦失業登記。失業保險金從登記那天起算，晚一個月就少一個月，單月金額按各省標準是數百到數千元一檔，落在「中」。第八十九條的賠償要你舉證損失，數額說不準，不據此拔高。
- 第 18 條：證據 A（財稅文件和法律原文）。收益定「大」、口徑「金錢」，按收益欄的例子機械套：36 萬元補償，有這條優惠交 3480 元，整筆按稅率表算是 58080 元，差 54600 元，是萬元級。補償金額小、不到 3 倍線的人，差額要看單位有沒有把它錯並進工資，這一檔的人收益更小。
