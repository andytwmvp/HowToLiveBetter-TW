## 閱讀前先看

閱讀頁面、生活自我檢視和離線閱讀檔都使用同一份臺灣版內容。閱讀器只會顯示目前收錄的指引。找不到想看的文章時，可以換個關鍵字，或從[章節目錄](locales/zh-TW/README.md)瀏覽；若仍找不到，表示目前沒有該主題的臺灣版指引。涉及統計或法規的文章會標明統計期間或適用日期；找不到可信的臺灣統計時，會說明資料限制，不把案件數直接當成個人發生機率。

在 GitHub 上直接開啟 HTML 檔，只會看到程式碼。想用瀏覽器閱讀，請依[閱讀說明](REPOSITORY_GUIDE.md#reading)在本機開啟閱讀頁面；也可以從[章節目錄](locales/zh-TW/README.md)直接開啟文章。
