## 閱讀前先看

網站閱讀頁、生活自我檢視和離線檔共用同一份台灣版內容，目前只顯示已收錄的指引。找不到主題時，可以換個關鍵字或從[章節目錄](locales/zh-TW/README.md)瀏覽；若仍找不到，表示目前沒有該主題的台灣版文章。文章會標明統計期間或法規適用日期；如果沒有可信的台灣統計，會說明資料限制，不把案件數或服務人次直接當成個人發生機率。

在 GitHub 上直接開啟 HTML 檔會看到程式碼。要用瀏覽器閱讀，請依[閱讀說明](REPOSITORY_GUIDE.md#reading)在電腦上啟動閱讀頁面；也可以直接從[章節目錄](locales/zh-TW/README.md)開啟文章。
