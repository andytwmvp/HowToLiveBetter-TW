## 臺灣版怎麼讀

臺灣版條目會交代適用對象、生活情境、可採取的步驟、成本與風險，以及來源與查閱日期。遇到法規或公共服務，也會區分公告日和施行日；沒有可信的臺灣統計時，會明說資料不足，不把案件數當成個人發生機率。

網站、自我檢視與離線閱讀檔使用同一份臺灣版內容。主題尚無可用指引時，閱讀器會直接說明，不會以原作或未完成查核的資料代替。

要在本機閱讀，請依[閱讀說明](REPOSITORY_GUIDE.md#reading)操作。GitHub 上直接點選 HTML 檔會看到原始碼，無法當成已部署的閱讀網站。

## 原作資料概況

以下數字描述原作的內容和編輯分類，不是臺灣生活風險統計。原作包含 765 條建議，分為 34 章；原作來源和臺灣版指引分開呈現。

全書 765 條中 A 級 495 條、B 級 218 條、C 級 52 條，另有 88 條標註了爭議、3 處標註了待核實。原作的 A／B／C 分級沿用原有判準，不代表臺灣版重新評等。

原作將 765 條建議按成本與效益分成三類：最高效益 122 條（16%）、高效益 344 條（45%）、一般 299 條（39%）。這是原作者採用其自身判準的分類，不代表臺灣版重新評估，也不保證個人能獲得相同效益。
